## 3. Post-run (CPU, ALWAYS runs, even after abort)

1. Validation sweep re-checks every artifact produced in the window (`run8h_validation.json`).
2. `geometry_router.py` re-eval including the new non-Llama alpha cells → is D3 still degenerate? (`D3_routing_eval_v2.json`)
3. `analyze_matrices.py` C3 nulls for every new 3-seed group (gemma, Phi, Qwen-3B, E6, KL-FT — whichever completed).
4. MEMIT vs ROME within-probe comparison table (if B2 ran).
5. `engine/run8h_report.txt`: per-job status (done/fail/config-skip/budget-skip), validation verdicts, and the four science questions answered/pending.

## 4. Abort / resume / preemption contract

- **Stop any time:** `engine/stop_deep_queue.sh engine/run8h.pid` (kills process group + descendants by PID).
- **Resume:** same launch command — completed cells skip; the truncated cell re-runs; budget restarts (deliberate: a resumed window is a new 8 h grant unless you shrink `BUDGET_MIN`).
- **Wedge abort (2 strikes)** ⇒ GPU queue stops, post-run CPU pass still executes, report says so.
- **Preflight or gate abort** ⇒ exit before any science; nothing to clean up.

## 5. Success criteria

Minimum (even with every new-code path failing): gemma 3-seed + Phi/Qwen-3B 2-seed hardening + report.
Target: + router triple (is D3 non-degenerate on weak-geometry archs?) + MEMIT×2 (law under a second editor)
+ QuantEdit vectors banked + anisotropy keys banked. Stretch: all Phase C admitted.
